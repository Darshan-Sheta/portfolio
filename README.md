# 🚀 Darshan Sheta - Professional Portfolio

Welcome to my personal portfolio repository! This project serves as a digital resume showcasing my skills, projects, and professional background. It is built with modern web development practices, focusing on high performance, elegant animations, and a clean user experience.

![Portfolio Preview](public/profile-photo.jpeg) <!-- Adjust image path if you have a specific preview screenshot -->

## ✨ Features

- 🎨 **Modern UI/UX**: Designed with a clean, developer-focused, glassmorphism aesthetic.
- 🌓 **Dark/Light Mode**: Full support for theme toggling tailored for perfect readability in any environment.
- 💫 **Smooth Animations**: Powered by Framer Motion for scroll reveals, magnetic buttons, and dynamic interactions.
- 📱 **Fully Responsive**: Optimized seamlessly for all screen sizes (Desktop, Laptop, Tablet, and Mobile).
- 📧 **Working Contact Form**: Integrated with Web3Forms for direct, hassle-free email messaging via AJAX without reloading pages.

## 🛠️ Technologies Used

- **Framework**: [React.js](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations / Physics**: [Framer Motion](https://www.framer.com/motion/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) (3D Particles)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started Locally

Follow these simple steps to run the project on your local machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Darshan-Sheta/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Launch**
   Open your browser and navigate to `http://localhost:5173`.
